# Evaluation & Iteration

Approach:
- Use ADDIE (Analysis, Design, Development, Implementation, and Evaluation) as the instructional-design framework.
- Use rapid prototyping during Development and Implementation: test materials and delivery with representative learners, gather feedback, and revise before scaling.
- Use evaluation findings throughout ADDIE to revisit earlier decisions.
- ADDIE itself is iterative: after completing Evaluation, return to Analysis and Design to identify needed changes to learner needs, assumptions, objectives, assessments, or instructional strategies. Develop and implement the revisions, then evaluate again.
- Pilot with representative learners and collect formative data before scale.

Friction logging quick method:
- Step, friction type (one of: Missing steps, Unclear instructions, Technical issue, Cognitive overload, Pacing, Accessibility, Other), severity (High = blocks task completion, Medium = slows or confuses but recoverable, Low = minor annoyance), recommended fix.

Metrics examples:
- Engagement (time-on-task), mastery (assessment criteria met), transfer (application in a new context), educational or organizational outcomes.
- Do not treat participation, completion, or satisfaction alone as evidence of learning.
